# 📚 JS-DSA — Data Structures & Algorithms in JavaScript

A collection of Data Structures and Algorithms problems solved using JavaScript to strengthen problem-solving skills, understand algorithmic concepts, and prepare for technical interviews.

## 🎯 Goals

- Build a strong foundation in Data Structures and Algorithms.
- Practice problems from basic to advanced levels.
- Understand brute-force, better, and optimal approaches.
- Analyze time and space complexity.
- Prepare for coding interviews and technical assessments.

## 🗂️ Topics Covered

- Basics & Complexity Analysis
- Arrays
- Sorting Algorithms
- Binary Search
- Strings
- Linked Lists
- Recursion & Backtracking
- Bit Manipulation
- Stacks & Queues
- Sliding Window & Two Pointers
- Hashing
- Trees & Binary Search Trees
- Heaps & Priority Queues
- Greedy Algorithms
- Graphs
- Dynamic Programming
- Tries

## 💻 Solutions

Each solution focuses on:

- **Approach:** Understanding the logic behind the problem.
- **Implementation:** Writing clean, readable JavaScript.
- **Optimization:** Exploring brute-force, better, and optimal solutions.
- **Complexity Analysis:** Evaluating time and space complexity.

## 🛠️ Tech Stack

- **Language:** JavaScript (ES6+)
- **Runtime:** Node.js
- **Practice Platforms:** LeetCode, GeeksforGeeks, and other coding platforms.

## ▶️ How to Run

Make sure [Node.js](https://nodejs.org/) is installed.

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/JS-DSA.git
```

Navigate to the project directory:

```bash
cd JS-DSA
```

Run a solution:

```bash
node Arrays/twoSum.js
```

Replace the file path with the solution you want to execute.
